# فال۴مير

ويجت فال و شاعري براي ويندوز و اندرويد — نمايش لحظه‌اي غزل‌ها و تفسير فال از **4mir.ir**

## نسخه‌ی ويندوز

کارت شناور (Always-on-top) نمايش‌دهنده:
- عکس غزل
- شماره و متن شاعري
- دکمه تازه‌سازي و صوت

### نصب و اجرا

```bash
pip install -r requirements.txt
python main.py
```
